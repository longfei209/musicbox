1.战斗界面的技能不用显示蓝量消耗和cd，把等级标上就行
2.把战斗界面的红蓝药瓶标记上数量
3.战斗界面的自动战斗没有快捷键，请设置一个
4.所有的esc没有实现返回功能，请加上
5.战斗结束后弹出结算窗口，掉落，经验等在结算界面体现并获得，不要每打死一只怪就获得经验，物品等，统一怪物组打完才结算后再获得物品材料等
6.升级经验适当再扩大一点，去对照经典传奇的逻辑，模仿一份升级经验系统过来，平衡一点，不然升级太快了
7.防御只是减免伤害，而不是对抗攻击力，搞个区间，如0-100防御是减免从0%-20%逐步上升，100-200又是21%-40%减免这种，你看着数据作出最佳方案，不一定是0-100,或100-200，具体根据等级装备加点的全方位来确定这个数值
8.宠物死亡后本场战斗不能复活，只有战斗结束了，复活冷却时间也到了才能复活
9.任务系统不要刷新那么快了，十分钟刷一次。任务多样化一点，奖励可适当平衡，删掉上交金币这个任务
